## About The Project - Beschreibung Deutsch
Dieses Projekt war ursprünglich eine Aufgabe für die dritte Mini PA (MPA). Es wird jedoch in diesem Repository weiterentwickelt. Das alte Repository ist [hier] (http://192.168.100.57:3000/Olivier_Luethy/MPA2_Prio) zu finden.

In diesem Projekt geht es konkret darum, Aufgaben welche man sich vornimmt, auch wirklich durchzusetzen. Z.B. setzt man sich oft viele neue Ziele für das neue Jahr, oder für das neue Alter. Das Problem ist nur, dass man sie nicht sinnvoll beschreibt und was man konkret erreichen möchte, damit es möglichst realistisch und erreichbar ist. Diese App soll dabei helfen, dieses Problem so gut es geht zu beheben.

In dieser App kann man Aufgaben oder Ziele hinzufügen, die man gerne erledigt oder erreicht haben möchte. Dabei definiert man einen Titel und beschreibt, was man gerne erreichen möchte und die Motivation dahinter. Wieso will man es erreichen und wo sind die benefits?

## Installation Guide

1. At first you need to install git on your local computer. For that you need to go to this [website](https://git-scm.com/downloads).
2. Go to your windows explorer and search for a good place for storing this project
3. Now right click on your folder or place and then click on "Git Bash Here"
4. Finally you will see a new program. If you do you only have to enter this
   ```sh
   git clone http://192.168.100.57:3000/Olivier_Luethy/Prio.git
   ```
